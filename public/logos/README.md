# HALBI METAL logo assets

현재 대화의 작업 폴더에서 원본 로고 첨부 파일이 확인되지 않아, 이 디렉터리는 교체 가능한 자산 슬롯으로 준비했습니다.

권장 파일명:

- `halbimetal-badge.svg` — 기본 벡터 배지
- `halbimetal-badge-light.svg` — 어두운 배경용
- `halbimetal-wordmark.svg` — 가로형 워드마크
- `halbimetal-badge-1024.png` — 소셜/미리보기용

원본을 추가한 뒤 `index.html`의 임시 `.badge` 요소를 `<img>`로 교체합니다. 로고 저작권과 사용 허가를 확인한 자산만 커밋합니다.
